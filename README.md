## Byzantine-Robust Federated Learning with WCGAN

<div align="justify">Federated learning is a way to jointly train multiple ML models without exposing the underlying data. It comprises multiple clients and a single server. The general flow looks like: the server shares a global model with a client subset (based on activity or network connection), clients train the said model on their local data and send back the updated weights, and then these updated weights are aggregated to output a new global model. Federated learning (FL) is preferred when data privacy and network latency are a concern. </div>
